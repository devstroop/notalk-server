Quick Connect

Use one of these configurations to connect an AI client to the MCP server.

VS Code (mcp.json)
{
  "servers": {
    "notalk": {
      "type": "http",
      "url": "",
      "headers": {
        "Authorization": "Bearer YOUR_API_KEY"
      }
    }
  }
}

Access Control

MCP access is controlled via API keys. Each key can be scoped to a specific account.

Manage API Keys ({{.Data.APIKeyCount}})

Security Note

MCP tools can send messages, manage groups, and access contacts. Create dedicated API keys with account-level scoping for each AI client. Never share the system secret key with MCP clients.
